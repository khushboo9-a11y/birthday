# 🎂 3D Birthday Scrapbook

A cute, aesthetic and interactive **3D scrapbook-style birthday website** made with ❤️

This project is designed as a digital memory album with:
- page flip animations 📖
- photos & videos 🖼️🎬
- emotional + funny notes 💌
- background music 🎶
- soft particles ✨

---

## 🌍 Live Demo

👉 [https://khushboo9-a11y.github.io/birthday/](https://khushboo9-a11y.github.io/birthday/)

---

## ✨ Features

- 📖 Realistic **page flip animation**
- 🖼️ Scrapbook-style photo layout
- 🎬 Video memory support
- 💌 Emotional + fun notes
- 🎶 Background music autoplay
- ✨ Floating particles for aesthetic feel
- ⬅️➡️ Next / Previous navigation
- 🎨 Warm retro + cozy design
